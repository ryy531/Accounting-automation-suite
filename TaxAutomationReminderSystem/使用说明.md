## 1. 系统概述

本系统从主客户表（`Copy of Client list master sheet`）自动拉取客户信息，按类型筛选后，每月在三个固定日期（1日、15日、25日）向客户发送提醒邮件。

**三种提醒类型：**

| 类型 | 筛选条件 | 发送邮箱 |
|------|----------|----------|
| Bookkeeping | Client Type = `Monthly` | 客户邮箱 |
| PST | PST Frequency = `Monthly` 或 `Quarterly` | 客户邮箱 |
| GST/HST | GST Frequency = `Monthly` 或 `Quarterly` | 客户邮箱 |

> Alex's 与 MK 工作表中无邮箱的客户，统一发送至 `staff.example@gmail.com`。

## 3. 首次使用准备

### 3.1 运行环境
- Windows 系统，已安装 **Python 3.8+**
- 安装时须勾选 **"Add Python to PATH"**
- 下载地址：https://www.python.org/downloads/

### 3.2 依赖包
双击 `run_reminder.bat` 时会自动检测并安装以下包：
- `msoffcrypto-tool`（读取加密 Excel）
- `openpyxl`（读写 Excel）
- `python-docx`（读取 Word 模板）

如自动安装失败，可手动在命令行运行：
```
pip install msoffcrypto-tool openpyxl python-docx
```

### 3.3 网络路径
程序支持两种路径，启动时自动检测哪个可用：
- 本机映射盘符：`Z:\4. General - Scan-Notes-Form-PPT\...`
- UNC 路径：`\\file-server\Shared Folder\...`

## 4. 模板文件说明

### 4.1 文件命名规范
模板文件存放于 `ReminderTemplet\` 文件夹，命名格式：
```
Monthly [类型] Reminder - [轮次] - ENG.docx
```
其中轮次为：`1st`（1日）、`15th`（15日）、`25th`（25日）

### 4.2 模板格式要求

**第一行必须为邮件标题行：**
```
Subject: [邮件标题内容]
```
此行将作为邮件主题，**不会出现在邮件正文**中。

**支持的占位符：**

| 占位符 | 替换内容 | 示例 |
|--------|----------|------|
| `{NAME}` | 客户联系人姓名 | Riley Yang |
| `{COMPANY}` | 公司法定名称 | ABC Holdings Inc. |
| `{MONTH}` | 当前月份 | March（英文）/ 3月（中文） |

**示例模板内容：**
```
Subject: Bookkeeping Reminder – March – ABC Holdings Inc.

Dear {NAME},

This is a friendly reminder that your monthly bookkeeping
documents for {MONTH} are due.

Please send your documents to our team at your earliest
convenience.

Best regards,
ExampleCo Group
Example CPA Firm P.C. Inc.
```

### 4.3 语言判断
- 客户主表中 `Language` 列为 `CN` → 月份显示为 `3月`、`4月`
- 其余情况（EN 或空）→ 月份显示为 `March`、`April`

> 注意：目前模板仅有英文版（ENG），中文模板待后续添加。

## 5. 每月操作流程

### 推荐操作顺序

```
每月 1日、15日、25日：

第一步：双击 run_reminder.bat
第二步：选择 [1] Update Tracker
        （输入主表密码，拉取最新客户数据，查看本轮待发名单）
第三步：选择 [2] / [3] / [4] 分别发送各类型，
        或选择 [5] Send All Three 一次性发送全部
第四步：确认发送 → 输入 SMTP 密码 → 完成
```

### 注意事项
- **[1] Update Tracker** 只更新数据，不发送邮件
- 若本月已完成某轮次，再次运行时该轮次的客户不会重复出现在待发名单中
- 新月份开始后，所有轮次自动重置，无需手动操作

## 6. 菜单功能详解

启动后主菜单显示当前日期和所处轮次：

```
============================================================
  Tax Reminder System   [2026-03-18]
  Current: March 2026  |  Round 1 (1st)
============================================================
  [1] Update Tracker        (read master -> update all 3 lists)
  ----------------------------------------
  [2] Send Bookkeeping      (Round 1 (1st))
  [3] Send PST              (Round 1 (1st))
  [4] Send GST/HST          (Round 1 (1st))
  [5] Send All Three        (Round 1 (1st))
  ----------------------------------------
  [6] Delete Client from Tracker
  [0] Exit
============================================================
```

| 选项 | 功能 | 需要密码 |
|------|------|----------|
| `[1]` | 从主表拉取数据，更新 Tracker，打印本轮待发名单 | 主表密码 |
| `[2]` | 发送 Bookkeeping 提醒 | SMTP 密码 |
| `[3]` | 发送 PST 提醒 | SMTP 密码 |
| `[4]` | 发送 GST/HST 提醒 | SMTP 密码 |
| `[5]` | 发送全部三种（SMTP 密码只需输一次） | SMTP 密码 |
| `[6]` | 从 Tracker 删除客户 | 无 |
| `[0]` | 退出程序 | 无 |

## 7. 发送轮次规则

每月自动判断当前轮次，无需手动切换：

| 日期范围 | 轮次 | 使用模板 |
|----------|------|----------|
| 1日 – 14日 | Round 1 (1st) | `- 1st -` 模板 |
| 15日 – 24日 | Round 2 (15th) | `- 15th -` 模板 |
| 25日 – 月底 | Round 3 (25th) | `- 25th -` 模板 |

**重置规则：**
- 每个轮次独立记录发送日期（R1SentDate / R2SentDate / R3SentDate）
- 新的一月开始后，三个轮次日期均自动视为过期，全部客户重新进入待发名单
- 同一轮次内重复运行不会重复发送（已发送的客户自动跳过）

## 8. Tracker 追踪表说明

`TaxReminder_Tracker.xlsx` 包含三个工作表：**Bookkeeping**、**PST**、**GST**

**列说明：**

| 列名 | 说明 |
|------|------|
| Legal Name | 公司法定名称 |
| Owner Name | 联系人姓名 |
| Owner Email | 发送邮箱 |
| Language | 语言（EN / CN） |
| Assigned | 负责人 |
| Client Type / PST Frequency / GST Frequency | 筛选依据 |
| Status | 当前状态（见下表） |
| R1SentDate | 第1轮发送日期（1日） |
| R2SentDate | 第2轮发送日期（15日） |
| R3SentDate | 第3轮发送日期（25日） |
| Notes | 备注（可手动填写） |

**Status 状态值：**

| 状态 | 含义 |
|------|------|
| `Active` | 正常接收提醒 |
| `R1 Sent` | 本月第1轮已发送 |
| `R2 Sent` | 本月第2轮已发送 |
| `R3 Sent` | 本月第3轮已发送 |
| `Inactive` | 已停用，不再发送（手动设置） |

> 如需临时暂停某客户的提醒，可在 Excel 中将其 Status 改为 `Inactive`，下次运行时该客户将被跳过。

## 9. 删除客户

选择菜单 `[6] Delete Client from Tracker` 后：

1. 输入客户名称（支持模糊搜索，如输入部分名称）
2. 系统显示所有匹配项（含所在工作表）
3. 输入编号删除单条，或输入 `A` 删除全部匹配项
4. 二次确认后删除，Tracker 自动保存

> **重要：** 删除操作仅从 Tracker 中移除记录，**不影响主客户表**。
> 下次运行 `[1] Update Tracker` 时，若该客户仍在主表中且符合筛选条件，会被重新加入 Tracker。
> 如需永久停用，建议将 Status 改为 `Inactive` 而非删除。

## 10. 常见问题排查

### Q1：运行 BAT 时提示"UNC paths are not supported"
**原因：** 在另一台电脑通过 UNC 路径（`\\server\...`）运行 BAT 文件时，旧版 CMD 不支持 UNC 作为当前目录。
**解决：** 当前版本已使用 `pushd` 命令修复，重新从服务器运行 BAT 即可。

### Q2：主表密码输入后提示解密失败
**原因：** 密码错误，或主表文件已更新但路径未同步。
**解决：** 确认密码正确；检查脚本顶部 `PATH_OPTIONS` 中的文件路径是否与当前主表文件名一致。

### Q3：GST / PST 客户数量为 0
**原因：** 主表中对应列的表头名称与脚本配置不匹配。
**解决：** 运行 `[1] Update Tracker` 时若有 `[WARN]` 提示，查看实际列名并更新脚本中 `CONFIG` 部分的 `col_gst_freq` / `col_pst_freq`。

### Q4：邮件发送失败（SMTP ERROR）
**原因：** SMTP 密码错误，或网络连接问题。
**解决：** 确认 SMTP 密码（`infosk@example-firm.com` 邮箱密码）；确认网络可访问 `smtp.hostinger.com:465`。

### Q5：Tracker 保存时提示"Permission denied"
**原因：** `TaxReminder_Tracker.xlsx` 正在 Excel 中打开。
**解决：** 关闭 Excel 中的 Tracker 文件，然后按提示按 Enter 重试，无需重新运行程序。

### Q6：模板内容未替换（收到邮件中仍显示 `{NAME}`）
**原因：** 占位符格式不正确（注意大括号为英文 `{}`，不是中文 `｛｝`）。
**解决：** 打开对应 `.docx` 模板，确认占位符为 `{NAME}`、`{COMPANY}`、`{MONTH}`。
