# `receipts/` 小票工具开发规则

`receipts/` 是小票工具的开发目录。所有小票工具修改必须先在这里完成。

## 工作边界

- 只在 `receipts/` 内开发、调试、修 bug
- 不直接修改 `receipts_pilot_v1.0/`
- 不把 dev 中未验证的文件同步到 pilot
- 不对 OCR、QuickBooks IIF、review workbook 等流程做顺手重写

## 修改纪律

- 一次只改一个文件，改完做最小验证
- 改前先读实际代码和相关测试/样本，不凭旧总结判断
- 对真实客户资料只做必要读取；不要复制、上传或写入无关位置
- 涉及 QuickBooks、金额、客户输出、邮件的动作都按 C 模式处理: 自动准备 + 人工确认
- 出现真实数据异常、AI 鉴权异常、QuickBooks 导入风险时先停下汇报

## 发布纪律

- 只有在 `receipts/` 中完成修改且相关测试通过后，才允许进入发布讨论
- 发布到 `receipts_pilot_v1.0/` 必须由 Riley 明确确认
- 发布同步是单独任务；不要在普通开发任务里顺手同步

## 验证

- 优先跑与改动相关的最小测试、smoke test 或 `py_compile`
- 不要为了验证而重跑大型真实 OCR 批次，除非 Riley 明确要求
- 最终汇报必须列出测试命令和结果
