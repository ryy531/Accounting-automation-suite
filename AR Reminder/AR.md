# AR Reminder – Email Template Writing Prompt

Use this file when asking an AI (ChatGPT, Claude, etc.) to write or revise the
three reminder email templates. Copy the prompt section and paste it directly.

---

## How to use

1. Copy everything under **"PROMPT (copy from here)"**
2. Paste into any AI chat
3. Paste the AI's output back to the developer to update `ar_reminder.py`

---

## PROMPT (copy from here)

I need you to write 3 accounts receivable reminder email templates for a CPA
firm. These templates will be used in a Python email automation system, so you
must follow the placeholder rules exactly.

---

### Firm Information

- **Firm name:** Example CPA Firm P.C. Inc.
- **Phone:** 555-000-0000
- **Email:** info@example-firm.com
- **Address:** 100 Example Street, Saskatoon, SK S7A 0A0
- **Interest policy:** 1% per month, charged after 30 days overdue

---

### Placeholder Rules

Use these placeholders exactly as written. The system replaces them automatically
at send time.

| Placeholder             | What it inserts                                             |
|-------------------------|-------------------------------------------------------------|
| `{{CLIENT_NAME}}`       | Client company name — e.g. "Example Resources Ltd."          |
| `{{DATE}}`              | Today's date — e.g. "March 19, 2026"                       |
| `{{INVOICE_COUNT}}`     | Number of overdue invoices — e.g. "3"                      |
| `{{TOTAL_BALANCE}}`     | Total outstanding balance — e.g. "CAD 5,991.00"            |
| `{{OVERDUE_BALANCE}}`   | Overdue portion only — e.g. "CAD 4,995.00"                 |
| `{{PREV_CONTACT_DATE}}` | Date of the previous reminder email (2nd and 3rd letter)   |
| `{{INTEREST_BLOCK}}`    | **[AUTO]** Red highlighted interest warning box. Do not    |
|                         | write interest text yourself. Place this tag where the     |
|                         | interest warning should appear.                            |
| `{{INVOICE_TABLE}}`     | **[AUTO]** Invoice detail table. Place this tag where the  |
|                         | invoice list should appear.                                |
| `{{SIGNATURE}}`         | **[AUTO]** Firm signature block. Always place at the end.  |

> Tags marked **[AUTO]** are generated by the system.
> Do not write their content — just place the tag in the correct position.

---

### Required Output Format

For each template, output exactly this structure:

```
TEMPLATE: [30d / 60d / 90d]
SUBJECT: <subject line>
BODY:
<email body using placeholders>
```

---

### Template Guidelines

#### Template 1 — 30d (First Notice / Friendly Reminder)

- **Tone:** Polite, professional, non-threatening
- **Content:**
  - Friendly reminder opening
  - State `{{INVOICE_COUNT}}` overdue invoices and `{{TOTAL_BALANCE}}`
  - Ask client to review records; invite contact if already paid or have questions
  - Place `{{INTEREST_BLOCK}}` after the main paragraph
  - Close with `{{INVOICE_TABLE}}` then `{{SIGNATURE}}`

#### Template 2 — 60d (Second Notice / Follow-Up)

- **Tone:** Firm but still professional, clearly urgent
- **Content:**
  - Reference previous contact on `{{PREV_CONTACT_DATE}}` with no response
  - State `{{TOTAL_BALANCE}}` (total) and `{{OVERDUE_BALANCE}}` (overdue portion)
  - Clearly state the 1% monthly interest policy is now in effect
  - Place `{{INTEREST_BLOCK}}` prominently
  - Request payment or contact to discuss arrangements
  - Close with `{{INVOICE_TABLE}}` then `{{SIGNATURE}}`

#### Template 3 — 90d (Final Notice / Collections Warning)

- **Tone:** Serious, direct, legal-tone warning
- **Content:**
  - Despite previous notices, balance remains unpaid
  - State `{{TOTAL_BALANCE}}`
  - Place `{{INTEREST_BLOCK}}` prominently near the top
  - Warn: firm reserves right to suspend services per contract
  - Warn: potential government penalties and credit record impact
  - Demand immediate payment or contact
  - Close with `{{INVOICE_TABLE}}` then `{{SIGNATURE}}`

---

### Formatting Rules

- Write in plain English paragraphs — no bullet points inside the email body
- Use `<b>bold</b>` tags for key figures: balance amounts, dates, phone number
- Wrap each paragraph in `<p>...</p>` tags
- Do **not** include any HTML wrapper tags (`<html>`, `<body>`, `<head>`) —
  the system adds those automatically
- Keep each template to 3–5 short paragraphs
- Do **not** write the firm's contact details — `{{SIGNATURE}}` handles that
